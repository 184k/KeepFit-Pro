# 💪 KeepFit Pro

AI 智能健身训练与饮食管理软件

## 📱 项目简介

KeepFit Pro 是一款面向健身用户的智能健身管理软件，帮助用户进行训练、饮食和身体数据管理，并通过 AI 提供个性化健身建议。

## ✨ 主要功能

- 🏠 BMI / 体脂率 / BMR 计算
- 🏋️ 健身动作库
- 🎬 训练动作视频
- 💪 胸部、背部、腿部、肩部、腹部训练
- 🍎 每日饮食记录
- 🥩 热量与营养素管理
- 🤖 AI 智能健身导师
- 📋 个性化训练计划
- 👤 用户头像与个人资料
- 📊 训练记录
- 💧 每日饮水与健身目标

## 🧠 AI 健身导师

根据用户的年龄、性别、身高、体重以及健身目标，为用户提供个性化训练和饮食建议。

## 🎯 健身目标

支持：

- 增肌
- 减脂
- 保持体型
- 提高身体素质
